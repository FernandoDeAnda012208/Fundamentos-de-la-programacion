## Niveles de lenguajes de programacion

Muy alto: Inteligencia artificial
Alto: Python
Medio: C
Bajo: Ensamblador

## Clasificacion de lenguajes de programación con base en su nivel 


| Clasificacion | Definicion                                                                                                                                  | Ejemplos     |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| Alto          | Son independientes del hardware y muy similares al lenguaje humano o matemático. Requieren un compilador o intérprete                       | Python, Java |
| Medio         | Tienen la estructura y legibilidad de un lenguaje de alto nivel, pero conservan la capacidad de manipular directamente el hardware          | C            |
| Bajo          | Muy cercano al hardware, pero usa palabras o mnemónicos más fáciles de recordar que el binario. El ejemplo principal es el **ensamblador**. | Ensamblador  |

| Tipo          | Definicion                                                                                                                                                                                                                          | Ejemplos                |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| Compilados    | Es el proceso y el resultado de convertir un programa escrito en un lenguaje de programación de alto nivel a código de máquina para que el procesador de la computadora pueda ejecutarlo directamente                               | c++, Java               |
| Interpretados | Es un tipo de lenguaje de programación cuyo código fuente no se compila previamente en un archivo binario ejecutable. En su lugar, un programa especial llamado intérprete lee, traduce y ejecuta las instrucciones línea por línea | Python, Javascript, php |
