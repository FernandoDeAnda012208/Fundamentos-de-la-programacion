
1.- No pueden usar una palabra reservada 
	ejemplos:
		- class
		- import
		- if
		- false
		- none
		- true
		- and
		- ass
		- break

2.- No pueden iniciar con numeros
		ejemplos:
			- 1auto
			- 4lugar

3.- No puede llevar signos aritmeticos
		ejemplos:
			- arbol+suelo
			- edad-promedio
